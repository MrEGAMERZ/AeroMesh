## Problem Statement
Build a single-pass drone video to 3D model generation tool for a hackathon demo. The system must look like a complete, highly accurate real product built by a company, proving undeniable metric scale.

## What Makes This Cool
Side-by-side augmented playback. As the original 2D drone video plays on the left, the generated 3D point cloud rotates perfectly in sync on the right. When the user draws a measurement line (e.g., across a bridge) in the 3D browser view, that measurement line dynamically projects and tracks onto the moving 2D video in real-time. This visibly proves that the 3D space maps 1:1 to reality.

## Constraints
- Hackathon timebox (48 hours).
- Must execute flawlessly on stage.

## Premises
1. The core "whoa" factor for the judges is proving metric accuracy in real-time, not just rendering a pretty 3D model.
2. To achieve this on a single drone pass without ground control points, the system must heavily fuse visual geometry with GPS/IMU telemetry.
3. The MVP should strip out the heavy Blender-style editing tools and focus entirely on the point-cloud/mesh viewer and metric measurement tools.

## Cross-Model Perspective
The independent Claude subagent correctly identified that the fastest path to a winning hackathon demo is nailing the "wow" interaction (the measurement tool) using a pre-baked asset first, before getting bogged down in live backend photogrammetry. It also generated the core lateral insight of this entire design: the side-by-side augmented playback to eliminate hallucination doubt.

## Approaches Considered
### Approach A: The Fast-Path Illusion (Minimal Viable)
Pre-bake a perfect 3D point cloud offline. Spend 90% of your weekend building a flawless React raycasting measurement UI. Fake the slow 3D reconstruction step for the live demo.

### Approach B: Full Pipeline Execution (Ideal Architecture)
Build the full `ReconstructionBackend` as spec'd in the Master Roadmap. Implement MapAnything and Kabsch-Umeyama SVD telemetry alignment for live, single-pass processing.

### Approach C: Side-by-Side Augmented Sync (Creative/Lateral)
Combine the 2D drone video feed alongside the 3D point cloud. Use camera projection matrices so that when you draw a measurement line in 3D, it dynamically overlays onto the moving 2D video.

## Recommended Approach
**APPROACH C: Side-by-Side Augmented Sync**
It provides the ultimate "gotcha" moment. Visually proving metric accuracy to the judges beyond any shadow of a doubt is the exact kind of magic trick that wins hackathons.

## Success Criteria
A user clicks two points on the 3D model to measure a span, sees the real-world distance (e.g., "14.23m"), and sees that exact same measurement line drawn perfectly over the original drone video footage.
